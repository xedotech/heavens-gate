# Brand — Heaven's Gate

_Status: active_

Heaven's Gate is an original open-world celestial-noir action game: a living city beneath a fractured afterlife where memory is currency and every gate changes the rules of reality.

## Direction

- Palette: **Aurelian Void** — obsidian blue-black, old ivory, and one sacred-gold signal color.
- Typography: Geist for interface clarity and Geist Mono for coordinates, telemetry, and tactical data.
- Voice: direct, mythic, specific. Short sentences. No empty claims about being “next-gen.”
- Motion: deliberate arrival, fast dismissal, no bounce. Gameplay feedback always wins over decoration.

## Core tokens

| Role | OKLCH | Purpose |
| --- | --- | --- |
| Background | `oklch(0.12 0.012 220)` | World shell and menu base |
| Foreground | `oklch(0.94 0.018 85)` | Primary type |
| Surface | `oklch(0.18 0.014 220 / 88%)` | HUD panels |
| Muted | `oklch(0.72 0.025 85)` | Secondary type |
| Primary | `oklch(0.82 0.12 82)` | Objectives, gates, focus, key actions |
| Danger | `oklch(0.64 0.19 28)` | Hostile and critical states only |
| Success | `oklch(0.76 0.13 150)` | Confirmed actions only |

The UI is dark-mode-first because it overlays a luminous real-time world. Critical text and controls meet WCAG AA contrast; focus uses the gold ring token.

## Do

- Let the world dominate the frame; keep the HUD quiet until it matters.
- Use gold for the supernatural system, objectives, and focus—not decoration.
- Pair monumental display type with restrained technical labels.
- Use hard-edged panels and circular sigils to echo city geometry and gates.

## Don't

- Do not use the generic violet-to-blue “AI product” gradient.
- Do not scatter glass cards across the screen.
- Do not mix multiple decorative accent colors.
- Do not copy Rockstar artwork, characters, logos, locations, or UI.
